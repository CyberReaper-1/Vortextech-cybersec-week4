# Vortex Tech Cyber Security Internship — Week 4 (Final Task)
## Mini Incident Response Plan

This repository contains my final deliverable for the Vortex Tech Cyber Security Internship track: a structured Incident Response Plan for a hypothetical healthcare data breach, built around the **NIST Incident Response Lifecycle** (Preparation, Detection & Analysis, Containment, Eradication, Recovery, Post-Incident Activity).

## Scenario

**MediCore Health**, a fictional telehealth/patient-portal provider, suffers a data exposure when an unauthenticated API endpoint allows unauthorized access to ~42,000 patient records (PHI). The scenario is modeled on real-world 2025–2026 healthcare breach patterns, where unsecured APIs and cloud-facing misconfigurations are among the fastest-growing initial access vectors in the sector.
